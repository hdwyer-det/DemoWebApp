This repository is to be used as a base for demonstrating the creation of a web application using flask.

It utilises:
* web server framework (flask)
* database (sqlite)
* template engine (jinja2 - packaged with flask)
* css library (bootstrap)

The following features are included:
* 3 web pages (Login form, Display of data from database, Arguments demonstration page)
* HTTP methods: GET (with and without arguments), POST
* Database interface
* Template Engine: Using partial pages to minimise duplicated code (e.g. menu)
* Template Engine: Formatting each row from database into a card
* Template Engine: Applying selection using a passed in parameter to use different HTML content
